# AI Enterprise Intelligence Platform

### AI-Powered Business Analytics & Decision Support System

An interactive business intelligence platform built with **Python, Streamlit, Plotly, Machine Learning, and Google Gemini AI** to transform business data into actionable insights and support data-driven decision-making.

The platform combines **business analytics, visualization, forecasting, AI-powered insights, inventory monitoring, customer analytics, employee analytics, and automated reporting** in a centralized application.

---

## 📌 Overview

The **AI Enterprise Intelligence Platform** provides a centralized environment for analyzing business operations across multiple areas, including:

* Sales and revenue
* Profitability
* Customers
* Products
* Inventory
* Employees
* Business performance
* Sales forecasting
* AI-assisted decision support

The project combines traditional **Business Intelligence (BI)** with **Machine Learning** and **Generative AI** to provide analytical insights and decision support.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/datasnitch/AI-Enterprise-Intelligence-Platform.git
```

### 2. Navigate to the Project

```bash
cd AI-Enterprise-Intelligence-Platform
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Environment

**macOS / Linux**

```bash
source venv/bin/activate
```

**Windows**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Gemini API

Create a `.env` file and add your API key:

```env
GEMINI_API_KEY=your_api_key_here
```

**Never upload `.env`, API keys, passwords, or other sensitive credentials to GitHub.**

### 7. Run the Application

```bash
streamlit run app.py
```
